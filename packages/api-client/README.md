# Bushpop API Client

Auto-generated TypeScript client from the Bushpop engine API's OpenAPI 3.1 spec.

Uses `openapi-typescript` + `openapi-fetch` for type-safe API calls.

## Generation
```bash
# Start API server, then:
curl http://localhost:3333/docs/json > openapi.json
npx openapi-typescript openapi.json -o src/schema.d.ts
```
