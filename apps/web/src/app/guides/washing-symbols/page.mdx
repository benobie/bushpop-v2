# Washing Symbols Decoder

Care labels pack a lot of information into a few small icons, and they matter even
more with secondhand clothing. A vintage or preloved piece might have a label
you have never seen before, a worn-off print, or an icon set that looks slightly
different from what is on your other clothes. This guide decodes every standard
laundry symbol so you can read a label with confidence, whatever the label style.

## Australia's care label system

Australia's mandatory rules for clothing care labels sit under the **Consumer
Goods (Care Labelling) Information Standard 2023**, which draws on the voluntary
Australian/New Zealand Standard **AS/NZS 1957:1998** and the international
standard **ISO 3758:2012** (the code of symbols maintained by GINETEX, the
international textile care labelling body). Under the standard, a supplier can
label a garment with written English care instructions, the five internationally
recognised care symbols, or both together, so you will see all three styles on
Australian racks.

**A genuinely useful thing to know for secondhand shopping:** the international
symbol system used in Australia, the UK and the EU shows the maximum wash
temperature as a **number inside the tub** (30, 40, 50, 60, 70 or 95, meaning
degrees Celsius). Dots inside the tub instead of a number are a **North American
convention**, not the Australian one. Secondhand and vintage pieces from US
brands often carry the dot system, so if you spot dots on a tub icon rather than
a number, treat it as a US-made label using the American convention, not a
different symbol family. The underlying icon shapes (tub, triangle, square, iron,
circle) are the same worldwide; it is mainly the wash-temperature notation that
differs.

## The five symbol families

Every care label is built from five icon shapes, each covering one stage of care:

| Shape | Covers |
|-------|--------|
| Tub (a basin with a wavy top) | Washing |
| Triangle | Bleaching |
| Square | Tumble drying |
| Iron outline | Ironing |
| Circle | Professional (dry) cleaning |

An **X through any symbol** always means "do not do this". A **single or double
line underneath** a symbol always means "reduced" or "extra gentle" handling for
that step, and is used across several of the symbol families below.

## Washing symbols

| Symbol description | Meaning |
|---------------------|---------|
| Plain tub, no number | Machine washable, no specific temperature limit given |
| Tub with a number (30, 40, 50, 60, 70 or 95) | Maximum wash temperature in degrees Celsius |
| Tub with a hand dipped in | Hand wash only, in water no warmer than 40°C |
| Tub with one line underneath | Gentle/permanent press cycle |
| Tub with two lines underneath | Extra gentle/wool or delicate cycle |
| Tub with an X through it | Do not wash (dry clean or spot clean only) |
| Tub showing dots instead of a number (1–6 dots) | US-convention temperature marker: more dots mean a hotter wash, roughly cold through to hot |

## Bleach symbols

| Symbol description | Meaning |
|---------------------|---------|
| Empty triangle | Any bleach, chlorine or non-chlorine, can be used |
| Triangle with two diagonal lines inside | Non-chlorine (oxygen) bleach only; no chlorine bleach |
| Triangle with an X through it | Do not bleach, of any kind |

## Tumble drying symbols

| Symbol description | Meaning |
|---------------------|---------|
| Square with a circle inside, no dots | Tumble dry, any heat |
| Square with a circle inside and one dot | Tumble dry on low heat |
| Square with a circle inside and two dots | Tumble dry on normal/medium heat |
| Square with a circle and an X through it | Do not tumble dry |
| Plain square with a horizontal line inside | Dry flat |
| Plain square with a curved line inside | Line dry / hang to dry |
| Square with vertical lines inside | Drip dry |

## Ironing symbols

| Symbol description | Meaning |
|---------------------|---------|
| Iron outline with one dot | Low heat, about 110°C: synthetics, acrylics |
| Iron outline with two dots | Medium heat, about 150°C: wool, polyester blends, silk |
| Iron outline with three dots | High heat, about 200°C: cotton and linen |
| Iron outline with an X through it | Do not iron |

## Dry cleaning symbols

| Symbol description | Meaning |
|---------------------|---------|
| Plain circle | Dry clean, any solvent |
| Circle with a "P" inside | Dry clean using perchloroethylene (the standard dry-clean solvent) |
| Circle with an "F" inside | Dry clean using a hydrocarbon solvent only |
| Circle with a line underneath | Dry clean with reduced mechanical action or reduced moisture |
| Circle with an X through it | Do not dry clean |

## Reading a label on a secondhand piece

- **A missing label is not a dead end.** Match the fabric by feel and go by the
  care advice for that fibre instead. See our [fabric care guide](/guides/fabric-care-guide/)
  for wool, denim, silk, leather and synthetics.
- **When in doubt, go gentler than the label suggests.** A cold hand wash and
  air dry is the safest default for anything you are unsure about, especially
  older or delicate pieces.
- **Test on a hidden seam first** if you are trying a new detergent or stain
  treatment on a piece with no readable label; check an inside hem or facing for
  colour fastness before treating the whole garment.
- **Faded or cracked prints happen with age.** If you can make out the icon shape
  but not the fine detail, use this guide to work out which symbol family it
  belongs to, then default to the gentlest reading of that shape.
